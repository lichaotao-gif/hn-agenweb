第 1 节 · 认识 Python 与编程思维

时长 12:30

本节带你认识 Python 语言与编程的基本思想，了解代码如何驱动计算机完成任务，建立学习信心。

课程介绍

本课程面向初中阶段零基础学生，以 Python 语言为载体，从最基础的变量、循环、函数讲起，逐步引导学生用代码解决真实问题。

课程采用双师 AI 课模式，注重计算思维的培养，每一节都配有课堂任务与拓展挑战，帮助学生在「做中学」，建立对人工智能与编程的兴趣和信心。

你将学到

  • Python 基本语法与数据类型
  • 条件、循环与函数
  • 简单的数据处理与可视化
  • 编写第一个智能小程序
